# NorthPeak Digital – Digital Heroes Internship Task

## 📌 Project Overview

NorthPeak Digital is a modern, responsive one-page agency website created as part of the **Digital Heroes Web Development Internship Qualification Task**.

The project was built using only **HTML5, CSS3, and JavaScript** without any frameworks or page builders.
